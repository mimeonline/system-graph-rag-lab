# Ideen-Assets

Dieses Verzeichnis enthält begleitende Artefakte zu Ideen unter `docs/product/ideas/`.

Hier liegen zum Beispiel:

1. PNGs und andere Bilddateien.
2. Eigenständige HTML-Prototypen.
3. Exportierte Visualisierungen.
4. Spätere Skizzen, Screenshots oder sonstige Vorschauartefakte.

Die eigentlichen Ideen bleiben als Markdown-Dateien direkt unter `docs/product/ideas/`. Artefakte werden aus den jeweiligen Ideen-Dateien heraus verlinkt.
