# Produktideen

## Zweck
Dieses Verzeichnis enthält lose Produktideen, Explorationsnotizen und frühe Produktgedanken.

## Regeln
1. Ideen sind keine Implementierungszusagen.
2. Eine Idee bleibt hier, bis sie bewusst in Roadmap, PRD, PDR oder SPEC überführt wird.
3. Begleitende Artefakte liegen unter `docs/product/ideas/assets/`.
4. Neue Ideen verwenden `docs/product/ideas/_template.md`.
