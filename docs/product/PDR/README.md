# PDR-Index

Dieses Verzeichnis enthält Product Decision Records mit langfristiger Wirkung auf Produkt, Scope, Positionierung oder Zielgruppenlogik.

## Trigger
Ein PDR erstellen, wenn:
1. Produkt-Scope oder Nicht-Ziele geändert werden.
2. Zielgruppe, Positionierung oder Nutzenversprechen geändert werden.
3. Eine Produktidee aus `docs/product/ideas/` bewusst in die Roadmap gezogen oder verworfen wird.
4. Discovery-Ergebnisse in verbindliche Produktentscheidungen überführt werden.

## Ablauf
1. Vorlage aus `docs/product/templates/PDR.md` kopieren.
2. Nummer und Kurztitel setzen.
3. Optionen, Entscheidung, Begründung und Auswirkungen dokumentieren.
4. Betroffene PRD-, Roadmap-, SPEC- oder ADR-Stellen verlinken.

## Benennung
1. `pdr-0001-<kurztitel>.md`
2. Nummerierung fortlaufend weiterführen.
