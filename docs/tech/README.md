# Tech

## Zweck
Dieses Verzeichnis enthält die technische Steuerung für System GraphRAG Lab.

## Inhalt
1. `SPEC.md`: maßgebliche technische Einstiegsspezifikation.
2. `architecture/`: arc42, C4-Sichten und Deployment-Sichten.
3. `ADR/`: Architekturentscheidungen.
4. `models/`: Daten- und Graphmodelle.
5. `spec/`: API-Vertrag, OpenAPI-Datei und Retrieval Contract.
6. `operations/`: lokale Entwicklung, Deployment, Observability, Vercel und Betriebsabläufe.
7. `templates/`: technische Vorlagen.

## Abgrenzung
1. Produktlogik, Scope und Roadmap gehören nach `docs/product/`.
2. Externe Quellen und Vergleichsnotizen gehören nach `docs/research/`.
3. Business- und Positionierungsnotizen gehören nach `docs/business/`.
4. Konkrete Feature-Schnitte gehören nach `docs/feature/`.
