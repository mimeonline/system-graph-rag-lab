# ADR-Index

Dieses Verzeichnis enthält Architekturentscheidungsprotokolle mit langfristiger Wirkung.

## Bestehende ADRs
Die vorhandenen ADRs wurden aus `docs/tech/ADR/` hierher migriert.

## Trigger
Ein ADR erstellen, wenn:
1. Routing, Datenmodell oder Informationsarchitektur technisch relevant geändert werden.
2. zentrale Bibliotheken oder Framework-Versionen geändert werden.
3. Deployment- oder Produktionsbetriebsmodell sich ändern.
4. sicherheitsrelevante technische Komponenten eingeführt werden.
5. technische Invarianten aus `AGENTS.md` geändert werden.

## Vorlage
Neue ADRs werden aus `docs/tech/templates/ADR.md` abgeleitet.
