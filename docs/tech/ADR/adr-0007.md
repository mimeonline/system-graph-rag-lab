# ADR-0007: Next.js-Sicherheitsaktualisierung auf 16.4.2

## Status
Accepted

## Datum
2026-10-23

## Kontext
Der beauftragte Sicherheitslauf mit `next upgrade --agent=security` bewertet die installierte Version 16.1.6 als von einer veröffentlichten Sicherheitsmeldung betroffen und empfiehlt 16.4.2.

## Entscheidung
Die Webapp verwendet Next.js in der exakten Version 16.4.2. Die bestehende Lint-Konfiguration eslint-config-next 16.1.6 bleibt erhalten; die Prüfung mit 16.4.2 meldete zusätzliche React-Hooks-Regelverstöße in bestehendem Anwendungscode. Die technische Versionsvorgabe in AGENTS.md folgt diesem Sicherheitsstand. `experimental.agentUpgrade` wird auf `security` gesetzt, sofern die Zielversion die Option unterstützt.

## Begründung
Die vom offiziellen Next.js-Werkzeug ermittelte Zielversion behebt die gemeldete Betroffenheit innerhalb derselben Hauptversion.

## Konsequenzen
Die Aktualisierung wird lokal durch Installation, Versionsprüfung, Typecheck, Lint, Tests und Build geprüft. Deployment und Veröffentlichung erfolgen auf gesonderten Auftrag.

## Gültigkeit
Gilt für die Webapp unter `apps/web`. Bei weiteren Sicherheitsmeldungen wird die Versionsvorgabe erneut geprüft.
