# Business

## Zweck
Dieses Verzeichnis ist für Business-, Markt-, Pricing-, Monetarisierungs- und Positionierungsnotizen vorgesehen.

## Aktueller Stand
Zum Zeitpunkt der Dokumentationsmigration vom 2026-06-19 liegen keine eigenständigen Business-Artefakte vor.

## Ablageregel
Neue Business-Notizen gehören hierher, wenn sie über reine Produktfunktionalität hinausgehen und Markt, Angebot, Pricing, Monetarisierung, Positionierung oder Vertrieb betreffen.
