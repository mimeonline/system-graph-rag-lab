# EU AI Act Quellen

## Zweck

Dieser Ordner enthält offizielle Quellmaterialien für eine mögliche EU-AI-Act-Demo im GraphRAG-Lernmodus.

Die Dateien dienen als Rohquelle für simulierte Graphvarianten, etwa Dokument-Graph, Wissensgraph, Domänen-Graph, Conversational Graph und dynamischer Graph.
