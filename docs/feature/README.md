# Feature

## Zweck
Dieses Verzeichnis enthält aktive Feature-Notizen, Feature-Schnittbeschreibungen und Übergänge aus Produktideen in konkrete Umsetzung.

## Abgrenzung
1. Produktvision, PRD, Roadmap und lose Ideen bleiben unter `docs/product/`.
2. Produktentscheidungen mit langfristiger Wirkung gehören nach `docs/product/PDR/`.
3. Technische Spezifikationen und Architekturentscheidungen gehören nach `docs/tech/`.
4. Historische Feature-Statusdateien werden nicht im aktiven Dokumentationsbaum gepflegt. Die Historie liegt in Git.

## Ablageregel
Neue Feature-Dokumente gehören hierher, wenn eine Produktidee oder Roadmap-Richtung konkret genug ist, um Umfang, Nutzerwert, Akzeptanzkriterien und Umsetzungsschnitt zu beschreiben.

## Mindestinhalt für Feature-Notizen
1. Ziel und Nutzerwert.
2. Umfang und Nicht-Ziele.
3. Akzeptanzkriterien.
4. Betroffene Produkt-, Tech-, Research- oder Business-Dokumente.
5. Offene Entscheidungen.
